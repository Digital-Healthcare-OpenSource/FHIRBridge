# Code of Conduct

FHIRBridge adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text at that link — including its enforcement guidelines —
is authoritative.

In short: be respectful, assume good faith, welcome newcomers and contributors from every
country and language, and keep discussions about the work. Harassment, personal attacks and
publishing others' private information are not tolerated.

This project handles health data. Never post real patient data (names, IDs, records — even
"anonymized" samples) in issues, pull requests or discussions; use synthetic data only.

## Scope

This code of conduct applies in all project spaces — issues, pull requests, discussions,
reviews — and when an individual officially represents the project elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainers through the repository's private
reporting channel:
**https://github.com/Digital-Healthcare-OpenSource/FHIRBridge/security/advisories/new**
(start the title with "Code of Conduct"). All reports are reviewed promptly and handled
confidentially. Maintainers enforce this code following the Contributor Covenant 2.1
enforcement guidelines.
